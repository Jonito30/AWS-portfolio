# Project 01 - Static Website on S3 + CloudFront

## What I Built
A personal static website hosted on Amazon S3 and delivered globally via CloudFront with HTTPS.

## AWS Services Used
- **S3** — stores the website files
- **CloudFront** — delivers the site fast worldwide and adds HTTPS
- **S3 Bucket Policy** — grants public read access to the files

## What I Learned
- How to create and configure an S3 bucket for static website hosting
- How to write an S3 bucket policy in JSON
- How to set up a CloudFront distribution
- The difference between HTTP and HTTPS
